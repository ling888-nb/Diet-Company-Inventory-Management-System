# 南通迪特金属制品有限公司进销存系统

## 项目简介

这是一个基于Vue 3 + Element Plus的现代化进销存管理系统，专为南通迪特金属制品有限公司设计。系统采用现代化的前端技术栈，提供直观的用户界面和强大的功能。

## 技术栈

- **前端框架**: Vue 3
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **路由管理**: Vue Router
- **构建工具**: Vite
- **Excel导出**: XLSX.js
- **样式**: CSS3 + 响应式设计

## 安装和运行

### 环境要求
- Node.js 16+
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 一键启动（Windows）
双击根目录的 `start.bat`。脚本会检查 Node.js/npm，缺少依赖时自动执行 `npm install`，然后启动开发服务。

### 开发模式运行
```bash
npm run dev
```

### 标准启动命令
```bash
npm start
```

### 构建生产版本
```bash
npm run build
```

### 预览生产版本
```bash
npm run preview
```

## 特色功能

### 智能编码生成
- **材料编码**: 自动生成材料编码，格式为"类型代码 + 序号"
- **订单号自动生成**: 材料入库、出库、回收订单号自动生成（MIN、MOUT、MREC前缀）
- **工艺编码**: 涂装工艺编码自动生成

### 涂装工艺与工艺组合关联优化
- **分离管理**: 工艺和组合分别管理，结构更清晰
- **关联显示**: 工艺表格显示使用情况，组合详情显示包含工艺
- **快速创建**: 支持选择多个工艺快速创建组合
- **详情查看**: 组合详情对话框显示完整工艺信息
- **使用统计**: 显示工艺被多少个组合使用
- **数据迁移**: 自动迁移现有复合工艺到新结构
- **重复工艺**: 支持在组合中重复添加相同工艺，最多10个工艺

### 数据管理

### 流转单系统
- 入库同步生成流转单
- 支持打印功能
- 产线信息记录

### 库存计算
- 实时库存计算
- 入库出库自动统计
- 库存预警功能

### 生产计划
- 按颜色分类生成
- 自动计算所需数量
- 考虑10%余量
- 复合工艺标记
